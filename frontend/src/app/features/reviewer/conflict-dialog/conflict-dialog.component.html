Declarar conflicto de interés

Declare un conflicto si tiene un vínculo con el manuscrito o con quienes lo escribieron que le impida evaluarlo con imparcialidad.

  • La asignación se libera sin penalización y el sistema la cubre con otro revisor.
  • Dejará de ver el manuscrito y no podrá guardar ni enviar la evaluación.
  • No se puede deshacer.
